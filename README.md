# go-api-template

A production-ready GitHub template for HTTP APIs in Go: start a new service with tested config, auth, observability and CI/CD already wired.

[![CI](https://github.com/martinezsaweczko/go-api-template/actions/workflows/ci.yml/badge.svg)](https://github.com/martinezsaweczko/go-api-template/actions/workflows/ci.yml)

## What you get

- **HTTP:** stdlib `net/http` routing (Go 1.22 patterns), graceful shutdown, liveness and readiness probes.
- **Middleware:** request ID, access log, panic recovery, CORS, body size limit, RS256 JWT authorization.
- **Config:** every setting as a flag or `APP_*` environment variable, validated at startup.
- **Observability:** OpenTelemetry tracing (OTLP gRPC), Prometheus metrics, JSON `slog` logs with trace IDs.
- **API docs:** OpenAPI generated by swag, served by Swagger UI.
- **Delivery:** distroless Docker image, GoReleaser binaries with provenance, multi-arch images on GHCR.
- **Quality:** race-enabled tests, golangci-lint, govulncheck, CodeQL, Dependabot, agent instructions in [`AGENTS.md`](AGENTS.md).

## Create a new project from this template

1. On GitHub, click **Use this template** > **Create a new repository**.
2. Clone it:

   ```bash
   git clone https://github.com/acme/orders-api.git && cd orders-api
   ```

3. Rename the module, app name and owner (add `--dry-run` first to preview):

   ```bash
   scripts/init.sh github.com/acme/orders-api orders-api acme
   ```

   It rewrites the module path, binary/image/service names, the OpenAPI title and CODEOWNERS, then runs `go mod tidy`, `make swagger`, `gofmt`, `go build` and `go test`. Pass `--copyright "Acme Inc."` to update `LICENSE`. Delete the script afterwards.
4. Generate the JWT signing keys (written to the gitignored `keys/`):

   ```bash
   make keys
   ```

5. Run the API:

   ```bash
   make run
   ```

6. Check it:

   ```bash
   curl -s localhost:8080/livez                # {"status":"ok"}
   curl -s localhost:8080/api/v1/version
   ```

   Swagger UI is at <http://localhost:8080/swagger/index.html>.

Use the Go version from the `go` directive in [`go.mod`](go.mod), for example through goenv, mise or asdf.

### Try the protected endpoint

The token endpoint is off by default. Enable it locally only:

```bash
./build/main -jwt-dev-token-endpoint &
TOKEN=$(curl -s -X POST localhost:8080/api/v1/token -d '{"subject":"dev"}' | sed 's/.*"token":"\([^"]*\)".*/\1/')
curl -s -H "Authorization: Bearer $TOKEN" localhost:8080/api/v1/dummyBusinessLogic
```

## Repository settings to enable

These live in GitHub settings, not in the code, so a new repository does not inherit them.

- [ ] **Template repository** (Settings > General), if this repository should itself be a template.
- [ ] **Branch protection or a ruleset on `main`**: require pull requests and the CI checks `Lint`, `Test`, `Vulnerability scan`, `Verify generated files and build`, `Docker build` and `Analyze (Go)`.
- [ ] **GHCR package visibility** (Packages > package settings) after the first image is published.
- [ ] **Private vulnerability reporting** (Settings > Security), used by [`SECURITY.md`](SECURITY.md).
- [ ] **Dependabot alerts and security updates** (Settings > Security).
- [ ] **Actions workflow permissions** (Settings > Actions > General): keep the default `GITHUB_TOKEN` read-only; workflows request the write scopes they need.

## Configuration

Precedence is **flag > environment variable > default**. Run `./build/main -h` to list everything.

| Flag | Environment variable | Default | Description |
| --- | --- | --- | --- |
| `-address` | `APP_ADDRESS` | `0.0.0.0` | HTTP listen address |
| `-port` | `APP_PORT` | `8080` | HTTP listen port |
| `-read-header-timeout` | `APP_READ_HEADER_TIMEOUT` | `5s` | Maximum time to read request headers |
| `-read-timeout` | `APP_READ_TIMEOUT` | `10s` | Maximum time to read the whole request (`0` disables) |
| `-write-timeout` | `APP_WRITE_TIMEOUT` | `10s` | Maximum time to write the response (`0` disables) |
| `-idle-timeout` | `APP_IDLE_TIMEOUT` | `1m0s` | Keep-alive idle timeout (`0` uses the read timeout) |
| `-shutdown-timeout` | `APP_SHUTDOWN_TIMEOUT` | `30s` | Graceful shutdown deadline |
| `-max-body-bytes` | `APP_MAX_BODY_BYTES` | `1048576` | Maximum request body size in bytes |
| `-cors-allowed-origins` | `APP_CORS_ALLOWED_ORIGINS` | empty | Comma-separated allowed origins, or `*` (empty disables CORS) |
| `-log-level` | `APP_LOG_LEVEL` | `info` | `debug`, `info`, `warn` or `error` |
| `-log-file-path` | `APP_LOG_FILE_PATH` | `stdout` | Log file path, or `stdout` |
| `-service-name` | `APP_SERVICE_NAME` | `go-api-template` | `service.name` reported in traces and metrics |
| `-otel-endpoint` | `APP_OTEL_ENDPOINT` | empty | OTLP gRPC trace endpoint as `host:port` (empty disables export) |
| `-metrics-path` | `APP_METRICS_PATH` | `/metrics` | Prometheus metrics path (empty disables metrics) |
| `-jwt-public-key-path` | `APP_JWT_PUBLIC_KEY_PATH` | `keys/public.pem` | JWT RSA public key |
| `-jwt-private-key-path` | `APP_JWT_PRIVATE_KEY_PATH` | `keys/private.pem` | JWT RSA private key |
| `-jwt-issuer` | `APP_JWT_ISSUER` | `go-api-template` | Issuer set on and required from tokens |
| `-jwt-audience` | `APP_JWT_AUDIENCE` | empty | Audience set on and required from tokens (empty disables the check) |
| `-jwt-token-ttl` | `APP_JWT_TOKEN_TTL` | `1h0m0s` | Lifetime of issued tokens |
| `-jwt-dev-token-endpoint` | `APP_JWT_DEV_TOKEN_ENDPOINT` | `false` | Enable the unauthenticated `POST /api/v1/token` (development only) |

## Endpoints

| Method | Path | Auth | Notes |
| --- | --- | --- | --- |
| GET | `/livez` | none | Liveness probe |
| GET | `/readyz` | none | Readiness probe; `503` until the server is ready |
| GET | `/api/v1/health` | none | Health status with timestamp |
| GET | `/api/v1/version` | none | Build version, time and app name |
| GET | `/api/v1/dummyBusinessLogic` | Bearer JWT | Example protected endpoint; replace it |
| POST | `/api/v1/token` | none | **Development only**, exists only with `-jwt-dev-token-endpoint` |
| GET | `/metrics` | none | Prometheus metrics (path set by `-metrics-path`) |
| GET | `/swagger/` | none | Swagger UI (`/swagger/index.html`) |

## Make targets

| Target | Description |
| --- | --- |
| `make keys` | Generate the RSA key pair in `keys/` if missing (`FORCE=1` overwrites) |
| `make run` | Build and run the API |
| `make build` | Build `build/main` with version metadata |
| `make test` | Run tests with the race detector |
| `make check` | Non-mutating gofmt, vet and module tidiness checks |
| `make fmt` | Format code and tidy modules |
| `make lint` | Run golangci-lint |
| `make vulncheck` | Run govulncheck |
| `make swagger` | Regenerate the OpenAPI docs in `docs/` |
| `make docker-build` | Build the container image |
| `make release-check` | Validate `.goreleaser.yaml` |
| `make clean` | Remove `build/` (`clean-swagger`, `clean-keys` remove `docs/` and `keys/`) |

## Project layout

```text
.
├── cmd/api/                    # entry point
├── docs/                       # generated OpenAPI docs (make swagger)
├── internal/
│   ├── app/                    # lifecycle and route registration
│   ├── config/                 # flags, APP_* env vars, validation
│   ├── model/                  # request and response types
│   ├── observability/          # OpenTelemetry and slog setup
│   ├── repository/             # persistence adapters
│   ├── service/                # business logic (JWT service)
│   └── transport/http/
│       ├── handlers/           # HTTP handlers
│       ├── middleware/         # middleware chain and authorization
│       └── server/             # http.Server wrapper
├── scripts/init.sh             # one-time template bootstrap
├── Dockerfile                  # multi-stage, distroless, non-root
└── .goreleaser.yaml            # release binaries and archives
```

## CI/CD

| Workflow | Trigger | What it does |
| --- | --- | --- |
| [`ci.yml`](.github/workflows/ci.yml) | push to `main`, pull requests | `make check` + golangci-lint, race tests with coverage, govulncheck, swagger drift and build, Docker build (no push) |
| [`release.yml`](.github/workflows/release.yml) | tag `v*.*.*` | tests, GoReleaser GitHub release (binaries, checksums, changelog), build provenance attestation |
| [`docker.yml`](.github/workflows/docker.yml) | tag `v*.*.*`, manual | multi-arch (`linux/amd64`, `linux/arm64`) image to `ghcr.io/<owner>/<repo>` with SBOM and provenance |
| [`codeql.yml`](.github/workflows/codeql.yml) | push to `main`, pull requests, weekly | CodeQL analysis for Go |
| [`dependabot.yml`](.github/dependabot.yml) | weekly | Go modules, GitHub Actions and Docker base image updates |

Cut a release from `main`:

```bash
git tag v1.2.3
git push origin v1.2.3
```

The changelog is built from [Conventional Commits](https://www.conventionalcommits.org/).

## Known trade-offs

- **Blank environment variables count.** A set but empty `APP_*` variable overrides the default (`APP_METRICS_PATH=` disables metrics); an empty numeric, duration or boolean value fails startup. Unset the variable to keep the default.
- **Tool fallbacks need network.** `make lint`, `make vulncheck` and `make release-check` use the installed binary, or download the pinned version with `go run`.
- **Provenance runs after publishing.** The attestation step runs after GoReleaser publishes, so a failed attestation leaves a release without provenance; re-run the job.
- **Flags were renamed** from the first version of this template:

  | Old | New |
  | --- | --- |
  | `-http-address` (default `localhost`) | `-address` (default `0.0.0.0`) |
  | `-http-port` | `-port` |
  | `-http-timeout` (seconds) | `-idle-timeout` (duration) |
  | `-http-read-timeout` (seconds) | `-read-timeout` (duration) |
  | `-http-write-timeout` (seconds) | `-write-timeout` (duration) |
  | `-o11-tracer-endpoint` | `-otel-endpoint` |
  | `-o11-prometheus-path` | `-metrics-path` |
