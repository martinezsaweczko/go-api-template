# AGENTS.md

Instructions for AI coding agents (Claude Code, Copilot, Codex, Cursor and others) working in this repository. This file is the single source of truth; `CLAUDE.md` imports it and `.github/copilot-instructions.md` summarizes it.

## Project

A production-ready template for HTTP APIs in Go: stdlib `net/http` routing, environment-based configuration, RS256 JWT authorization, OpenTelemetry tracing, Prometheus metrics, structured `slog` logging, health probes, generated OpenAPI docs, a distroless Docker image and GitHub Actions CI/CD.

## Layout

```text
cmd/api/                         entry point: config, logger, telemetry, server wiring
internal/app/                    App lifecycle; handlers.go builds handlers and registers routes
internal/config/                 flags + APP_* env vars, defaults and validation
internal/model/                  request/response types (also used by swagger)
internal/observability/          OTel SDK setup, slog trace handler
internal/repository/             persistence adapters (empty placeholder)
internal/service/                business logic (JWTService)
internal/transport/http/
  handlers/                      HTTP handlers, writeJSON helper, Router interface
  middleware/                    tracing, metrics, request ID, logging, recovery, CORS, body limit, auth
  server/                        http.Server wrapper with middleware chain
docs/                            GENERATED by swag; never edit by hand
scripts/init.sh                  one-time bootstrap for projects created from the template
scripts/init_test.sh             its test, run by `make test-init`
```

## Commands

Use the Go version from the `go` directive in `go.mod` (for example through goenv, mise or asdf).

| Command | What it does |
| --- | --- |
| `make keys` | Generate the RSA key pair in `keys/` (skips if present; `FORCE=1` overwrites) |
| `make run` | Build and run the API on `0.0.0.0:8080` |
| `make build` | Build `build/main` |
| `make test` | `go test -race -count=1 ./...` |
| `make check` | gofmt check, `go vet`, `go mod tidy -diff` (non-mutating) |
| `make fmt` | `gofmt -w .` and `go mod tidy` (mutating) |
| `make lint` | golangci-lint (binary, else pinned `go run`) |
| `make swagger` | Regenerate `docs/` with swag |
| `make vulncheck` | govulncheck (binary, else pinned `go run`) |
| `make docker-build` | Build the container image |
| `make release-check` | Validate `.goreleaser.yaml` |
| `make test-init` | Test `scripts/init.sh` in throwaway copies of the repo |

Before finishing any change: `make check lint test`. Run `make swagger` when handler annotations or `internal/model` change. Run `make test-init` (and shellcheck) when `scripts/init.sh` or `scripts/init_test.sh` change, and when adding files that mention the template's module, app name or owner.

## Conventions

- **Routing:** stdlib `net/http` with Go 1.22 method patterns (`"GET /api/v1/version"`). No router frameworks.
- **Dependency injection:** constructors take a `*Config` struct of dependencies (`(&handlers.VersionHandlerConfig{...}).NewVersionHandler()`). No package-level mutable state or globals.
- **Context:** pass `r.Context()` (or a derived ctx) down every call; never use `context.Background()` inside a request path.
- **Logging:** `log/slog` only, injected as `*slog.Logger`. Use the `*Context` methods (`InfoContext`, `ErrorContext`) so records carry `trace_id` and `span_id`.
- **Errors:** wrap with `fmt.Errorf("doing x: %w", err)`; check with `errors.Is` / `errors.As`. Never ignore an error silently.
- **Responses:** write JSON with `writeJSON(w, status, v)` in `internal/transport/http/handlers/json.go`; errors use `model.HTTPError`.
- **Configuration:** add settings in `internal/config` with a flag, a default constant and validation. Each flag maps to an `APP_` env var (`-jwt-token-ttl` -> `APP_JWT_TOKEN_TTL`). Precedence is flag > env > default. `config.Load(args, lookupEnv)` takes the environment as a function, so tests pass a map instead of touching `os.Environ`.
- **Auth claims:** read validated JWT claims with `middleware.ClaimsFromContext(ctx)`.
- **Style:** gofmt + goimports with the module path as local prefix; golangci-lint config in `.golangci.yml`.

## How to add an endpoint

1. **Model:** add request/response structs to `internal/model/` with `json` tags.
2. **Service:** put business logic in `internal/service/` behind a constructor; storage goes in `internal/repository/` behind an interface the service owns.
3. **Handler:** add `internal/transport/http/handlers/<name>.go` following `version.go` or `dummy.go`:
   - a `<Name>HandlerConfig` struct and a `New<Name>Handler()` constructor;
   - `RegisterRoutes(router Router, middlewares ...middleware.Middleware)` registering `"<METHOD> " + basePath + "/<path>"`;
   - swag annotations (`@Summary`, `@Tags`, `@Param`, `@Success`, `@Failure`, `@Router`, plus `@Security Bearer` when protected).
4. **Wire:** in `internal/app/handlers.go`, build the handler in `initHandlers` (add a field to `Handlers` in `app.go`) and register it in `registerRoutes`. Pass `authorizationMiddleware` for protected routes.
5. **Test:** add table-driven tests next to the handler (see "Testing").
6. **Docs:** run `make swagger` and commit `docs/` with the change.

## Testing

- Table-driven tests with `t.Run`; `httptest.NewRecorder` / `httptest.NewServer` for HTTP.
- Always run with the race detector (`make test`).
- Tests generate throwaway RSA keys in `t.TempDir()`; never read `keys/`.
- No network access, no fixed ports, no sleeps for synchronization.
- Keep tests in the same commit as the behavior they cover.

## Observability

- Tracing is applied globally by `middleware.Tracing` (otelhttp). Start child spans only for meaningful units of work and pass the returned ctx down.
- `middleware.Metrics` owns request count and duration metrics for every route. Do not add per-handler request counters.
- Probes (`/livez`, `/readyz`) and the metrics path are not traced and are logged at Debug.

## Security

- Never commit `keys/`, `.env`, tokens or credentials.
- JWTs are RS256 only; expiry is always required, issuer and audience are checked when configured (the issuer has a default).
- `POST /api/v1/token` mints tokens without authentication. It exists only when `-jwt-dev-token-endpoint` (`APP_JWT_DEV_TOKEN_ENDPOINT=true`) is set. Never enable it by default or in production.
- Report vulnerabilities as described in `SECURITY.md`.

## Do not touch

- `docs/`: generated by `make swagger`.
- `keys/`: local secrets, gitignored.
- The `go` directive in `go.mod` and `.go-version`, unless the task is a Go upgrade.
- Pinned tool versions in `Makefile` and workflows: change them together (see the comments next to each).

## Commits and pull requests

- [Conventional Commits](https://www.conventionalcommits.org/): `feat:`, `fix:`, `refactor:`, `test:`, `docs:`, `build:`, `ci:`, `chore:`. The release changelog is generated from them.
- One work unit per commit, with its tests and docs.
- Before pushing: `make check lint test` green and `docs/` regenerated if annotations changed.
- Fill in `.github/PULL_REQUEST_TEMPLATE.md`.
